# Blazor-Diagram-Organizational-Layout
A Syncfusion Blazor Diagram sample that showcases the Organizational Chart layout in the Blazor Diagram component.

## How to Run the Blazor WebAssembly Application
 
This sample is intentionally designed with a minimal amount of code to demonstrate the creation of an organizational chart diagram with large nodes and connectors. Users can interact with the diagram by selecting, dragging, resizing, and editing nodes and connectors.
 
### Prerequisites
 
Before running the application, ensure that the following are installed:
 
- .NET SDK
- Visual Studio 2022 or later (optional)
- A modern web browser such as Microsoft Edge, Google Chrome, or Firefox
 
### Run Using Visual Studio
 
1. Open the solution file (`.sln`) in Visual Studio.
2. Restore the NuGet packages.
3. Set the Blazor WebAssembly project as the Startup Project.
4. Press **F5** or select **Start Debugging**.
5. The application will build and launch in the default browser.
 
### Run Using .NET CLI
 
Navigate to the project directory and execute the following commands:
